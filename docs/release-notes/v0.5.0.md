LaunchWizard 0.5.0 fixes every problem found in the October 2026 audit and delivers the full Pro feature set.

**Install:** download `launchwizard-0.5.0.vsix` below, then in VS Code, Cursor or Antigravity run **Extensions: Install from VSIX…**.

## Fixed
- The pre-flight check could report "All clear" when TypeScript wasn't installed in the project, timed out, or failed with unreadable output. It now reports a clear blocker instead.
- The env-variable "fix" could publish secrets to the browser. Secret-looking variables now get an explanation, never a "make it public" fix.
- Fixes were written to disk with no preview or undo. They now show a diff first, go through the editor (Ctrl+Z works), and "Undo Last Fix" restores the files.
- After a provider fallback or port switch, "Stop" could leave a link running. Every link now stops completely.
- Pro could be unlocked without a valid purchase. Licensing now uses Gumroad's license API, with a 3-machine limit and a weekly re-check.
- New Cloudflare links could look dead for minutes on Windows when opened too early. Links are announced only once they work.
- Plus: cancellable link startup, IPv6 dev servers, framework-aware lightbulbs, debounced on-save checks, live link status, clickable error cards, and a locked-down sidebar.

## New for everyone (free)
- Full production build check: runs your real `build` script and explains failures in plain English.
- Detects a missing `'use client'`, import paths with the wrong letter case (they break Linux builds), and `.env` values cut off at `#`, with 1-click fixes.
